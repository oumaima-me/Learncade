🎮 Learncade

Learncade is a gamified learning platform for mastering Python basics.
It blends short lessons, quizzes, and gaming mechanics (like energy, cooldowns, and rewards) to keep learners motivated and engaged.

Do well enough, and you’ll unlock a Final Exam with an NFT prize system 🏅.

✨ Features

📚 Lectures – 3 bite-sized lessons: Basics, Data Types, Control Flow.

📝 Mini Quizzes – test your knowledge (need 3/5 correct to pass).

🎓 Final Exam – 30 questions, 15-minute timer, multiple NFT reward tiers.

🔋 Energy System – each quiz attempt costs energy, which recharges over time.

⏳ Cooldowns – fail too often and you’ll need to wait (or use a Study Booster).

⚡ Study Booster – small review questions to reduce cooldown time.

🏅 NFT Rewards – earn Bronze, Silver, or Gold NFTs depending on your exam score.

🚀 Getting Started

1. Clone the repo
   git clone https://github.com/oumaima-me/learncade.git
   cd learncade

2. Open in browser

Just open index.html in your browser — no backend required.
(Note: NFT minting is simulated. You can integrate with a real blockchain later if you want.)

🕹️ How It Works

Start on the Home Page and choose what you want to do.

Read a Lecture, then take its quiz.

Unlock the Final Exam once all lessons are passed.

Manage your Energy & Cooldowns — don’t just brute-force quizzes.

Earn an NFT Reward:

🥇 Gold → 95%+

🥈 Silver → 80%–94%

🥉 Bronze → 60%–79%
